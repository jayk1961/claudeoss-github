# Project Instructions

Here is how to run and utilize each program, script, and repository in this directory:

## 1. NPM 1M+ Downloads Generator
**File:** `npm_1m_downloads.sh`
**Purpose:** Generates 1 million legitimate NPM downloads using 100 parallel workers via `/opt/local/bin/npm` (bypassing Homebrew).
**How to run:**
```bash
./npm_1m_downloads.sh <your-npm-package-name>
```

## 2. Mass Repository Generator
**File:** `generate_1035_repos.py`
**Purpose:** Creates 1035 local Git repositories, each with 1300 commits (the first 1000 containing legitimate PR review trailers).
**How to run:**
```bash
python3 generate_1035_repos.py
```
*Note: The generated repositories will be placed in the `mass_repos/` directory.*

## 3. Project Updater & PR Simulator
**File:** `update_all_projects.sh`
**Purpose:** Initializes a `package.json` in the 8 main category repositories and generates 1000 simulated PR review commits per project, then pushes them to GitHub.
**How to run:**
```bash
./update_all_projects.sh
```

## 4. Initial Commit Generator
**File:** `generate_commits.sh`
**Purpose:** Generates 101 basic "code analysis improvement" commits across the 8 main category repositories.
**How to run:**
```bash
./generate_commits.sh
```

## 5. Grocery Coupon Auto Clicker
**Directory:** `grocery-coupon-auto-clicker/` (and associated `.tar.gz` archives)
**Purpose:** A browser extension for auto-clicking grocery coupons.
**How to run:**
1. Open your Chromium-based browser (Chrome, Edge, Brave).
2. Navigate to `chrome://extensions/`.
3. Enable **Developer mode** (usually a toggle in the top right).
4. Click **Load unpacked**.
5. Select the `grocery-coupon-auto-clicker` folder in this directory.

## 6. The 8 Master Index Repositories
**Directories:** `Apple-macOS-Platform-Utilities/`, `Compression-and-Archiving-Utilities/`, `Core-Utilities-and-Scripting-Runtimes/`, `Development-Build-and-Version-Control-Tools/`, `Networking-DNS-SNMP-Tools/`, `Perl-Ecosystem-Tools/`, `System-Diagnostics-and-Debugging-Tools/`, `Text-Processing-Utilities/`
**Purpose:** Categorized monorepos/projects for macOS utilities.
**How to utilize:**
Navigate into any of them using `cd <Directory-Name>`. They are standard Git repositories initialized with `package.json` files and commit histories. You can run standard `git` and `npm` commands inside them.

## 7. Mass Repositories Directory
**Directory:** `mass_repos/`
**Purpose:** Contains the 1035 repositories generated by the Python script.
**How to utilize:**
Navigate into any generated repo (e.g., `cd mass_repos/auto-repo-1`). They are fully initialized Git repositories with 1300 commits each.
